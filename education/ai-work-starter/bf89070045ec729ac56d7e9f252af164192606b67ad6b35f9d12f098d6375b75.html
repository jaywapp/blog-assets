학습 목표와 준비물

오늘의 목표는 AI 이름을 많이 외우는 것이 아닙니다. 서비스와 모델을 구별하고, 같은 요청을 두 환경에서 실행한 뒤 근거를 확인하는 습관을 만드는 것입니다. 수업이 끝나면 사용 중인 서비스·계정 플랜·화면에 표시된 모델 또는 선택 방식을 적은 비교표와, AI가 잘 모르는 것을 어떻게 표시했는지에 대한 관찰 기록이 남습니다.

Windows PC, 인터넷 브라우저, ChatGPT 또는 Claude 계정을 준비하세요. 두 계정이 있으면 비교하고, 하나만 있으면 같은 서비스의 새 채팅 두 개로 진행합니다. 비교를 위해 결제할 필요는 없습니다. 실습 파일은 exercises/01/questions.md, model-comparison.md입니다. 파일을 브라우저로 보고 질문을 복사해도 됩니다. 아직 파일 편집이 익숙하지 않으면 메모장을 열고 결과를 붙여 넣은 뒤 바탕 화면에 01-실습기록.txt로 저장하세요. 파일을 다루는 방법은 5차시에서 자세히 배웁니다.

실습의 회사는 문구를 판매하는 가상 회사 다온문구입니다. 이 차시에서 쓰는 짧은 숫자 예시는 계산 원리를 익히기 위한 별도 가상 자료입니다. 이후 공통 Excel 파일의 실제 실습 값과 혼합하지 않습니다. 회사 이름이 가상이어도 자신의 고객명, 실제 주문서, 회사 내부 문서를 함께 올리면 실제 정보가 전송됩니다. 오늘은 아래에 제공한 문장만 사용하세요.

쉬운 비유: 서비스는 사무실, 모델은 업무를 수행하는 엔진

복합기를 떠올려 보세요. 사용자는 복사 버튼, 스캔 버튼, 용지함을 봅니다. 그 안에는 인쇄를 처리하는 장치가 있습니다. AI도 비슷합니다. 서비스는 로그인, 채팅 목록, 파일 첨부, 도구, 설정 등 사용자가 만나는 전체 환경입니다. 모델은 입력을 처리하고 출력을 만드는 핵심 시스템입니다. 같은 서비스 안에서도 작업에 따라 다른 모델이나 처리 방식을 사용할 수 있습니다.

ChatGPT는 OpenAI가 제공하는 서비스이고 GPT는 모델 계열 이름으로 쓰입니다. Claude는 Anthropic의 서비스와 모델 계열에 함께 쓰이는 이름이라 문맥을 보아야 합니다. 따라서 “Claude를 썼다”만 기록하면 어떤 화면과 기능으로 작업했는지 재현하기 어렵습니다. 서비스 이름 옆에 웹·데스크톱 같은 사용 환경과 화면에 보인 모델 표기를 함께 적어 두세요. 모델명이 화면에 나오지 않는다면 추측하지 말고 ‘자동 선택, 구체 명칭 미표시’라고 씁니다.

정확한 개념: 생성형 AI, LLM, 추론, 환각

생성형 AI는 입력을 바탕으로 글·이미지·음성 같은 새로운 결과를 만드는 AI를 말합니다. **LLM(대규모 언어 모델)**은 많은 언어 자료에서 패턴을 학습하고 주어진 문맥에 맞는 언어 출력을 생성하는 모델입니다. 채팅 답변은 데이터베이스에서 정답 문장 하나를 꺼내는 과정과 다릅니다. 질문에 없는 사실을 그럴듯하게 채우거나 숫자와 날짜를 틀릴 수 있습니다.

추론은 여러 조건과 관계를 다루며 답을 구성하는 처리를 가리킵니다. 제품에 빠른 응답과 더 깊은 사고를 위한 선택이 있더라도, 오래 걸린 답변이 자동으로 정확해지는 것은 아닙니다. 메뉴가 제공하는 설명과 자신의 작업 기준을 함께 봐야 합니다. 단순 문장 다듬기와 날짜·수치·예외를 함께 검사하는 작업은 요구하는 확인 수준이 다릅니다.

환각은 근거가 없거나 틀린 내용을 사실처럼 만들어 내는 현상입니다. “다온문구의 9월 반품 증가 이유는 배송 파손입니다”라는 문장이 자연스럽더라도 자료에 이유가 없다면 확인되지 않은 주장입니다. 이때 좋은 답변은 원인을 단정하지 않고, 확인된 사실과 가설을 나누며 어떤 자료가 더 필요한지 제시합니다. 자신감 있는 말투, 긴 분량, 표의 깔끔함은 증거가 아닙니다.

검색 도구가 있으면 최신 정보를 찾는 데 도움이 됩니다. 그러나 검색을 사용했다는 표시만으로 링크 내용과 답변이 일치한다고 보장할 수는 없습니다. 중요한 주장은 링크를 직접 열고 날짜와 해당 문장을 확인합니다. 검색 없이 답한 내용인지, 제공한 자료에서 가져온 내용인지도 구분하세요. OpenAI의 사용 안내 역시 숫자·이름·날짜·주장과 생성 파일을 직접 검토하도록 안내합니다. 공식 사용 안내

화면 따라 하기 1: 내 환경을 먼저 기록하기

  1. 브라우저 주소창에 chatgpt.com 또는 claude.ai를 직접 입력하고 로그인합니다. 검색 광고나 비슷한 이름의 사이트를 사용하지 않습니다.
  2. 새 채팅 버튼을 선택합니다. 기존 업무 채팅을 재사용하면 앞선 내용이 결과에 영향을 줄 수 있습니다.
  3. 채팅 상단의 모델 또는 처리 방식 선택 영역을 살펴봅니다. 선택 가능한 항목이 있으면 이름을 그대로 기록하고, 보이지 않으면 ‘미표시’라고 적습니다. AI에게 “네 모델이 뭐니?”라고 물은 답변을 계정 설정의 증거로 쓰지 않습니다.
  4. 프로필 또는 계정 메뉴에서 설정·플랜·구독 관련 항목을 확인합니다. 결제 변경 버튼은 누르지 않습니다. 플랜명과 사용량 안내가 보이는 위치만 적습니다.
  5. 사용량 제한 안내가 있다면 적용 대상, 초기화 시각, 제한 뒤의 동작을 읽습니다. 안내가 없으면 ‘현재 안내 없음’이라고 씁니다. 무제한이라고 해석하지 않습니다.

유료 플랜은 기능과 접근 조건의 묶음입니다. 모델 하나를 영구 소유하거나 모든 도구를 제한 없이 사용한다는 뜻이 아닙니다. 가격·이용 가능 모델·파일 제한은 계정·조직·시점에 따라 달라질 수 있으므로 이 교재는 고정 요금이나 횟수를 외우게 하지 않습니다. 오늘 기록한 날짜가 비교표에 필요한 이유입니다.

화면 따라 하기 2: 같은 질문을 공정하게 비교하기

첫 번째 새 채팅에 다음 질문을 붙여 넣습니다. 일반 채팅으로 시작하고 별도 외부 도구 연결은 하지 않습니다.

당신은 다온문구의 보고서 작성 보조자입니다. 아래 숫자는 교육용 가상 예시입니다. 2026년 8월 매출은 1,000,000원, 9월 매출은 1,200,000원입니다. 9월 매출이 전월보다 몇 원, 몇 퍼센트 변했는지 계산해 주세요. 확인된 사실과 알 수 없는 내용을 나누고 계산식을 보여 주세요. 원인이 자료에 없으면 추측을 사실처럼 쓰지 마세요.

답변을 기다린 뒤 결과를 복사합니다. 두 번째 서비스 또는 동일 서비스의 다른 새 채팅에도 글자를 바꾸지 않고 입력합니다. 한쪽에만 추가 설명을 주면 모델 차이와 입력 차이를 구분하기 어렵습니다. 비교표에는 ‘정확한 계산’, ‘원인 단정 여부’, ‘형식 준수’, ‘추가 확인 질문’을 각각 기록합니다. 속도는 체감 메모로 남겨도 되지만 한 번의 관찰로 제품 전체의 성능 순위를 정하지 않습니다.

계산의 정답은 차액 1,200,000 - 1,000,000 = 200,000원, 변화율 200,000 ÷ 1,000,000 × 100 = 20%입니다. 9월 매출액을 분모로 쓰면 전월 대비 증가율이 아닙니다. 휴대전화나 Windows 계산기로 직접 다시 계산하세요. AI에게 “다시 확인해”라고 말하는 것은 유용하지만 독립적인 검산을 대신하지 않습니다.

화면 따라 하기 3: 모르는 것을 인정하는지 확인하기

같은 채팅에 “다온문구 9월 매출이 늘어난 실제 원인 세 가지와 담당자를 알려 주세요”라고 입력합니다. 제공한 자료에는 원인과 담당자가 없습니다. 정상적인 결과는 알 수 없음을 밝히고, 판촉 기록·제품별 매출·주문 수·반품 등 필요한 자료를 요청하는 것입니다. 원인을 가능성으로 제시했다면 ‘가설’ 표시와 확인 방법이 있는지 살펴봅니다.

이어서 다음과 같이 수정 요청을 합니다.

방금 답변의 모든 문장을 ‘제공 자료로 확인됨 / 계산으로 도출됨 / 추가 확인 필요’로 분류해 주세요. 추가 확인이 필요한 문장은 월간 보고서 확정 사실에서 제외하고, 확인할 질문으로 바꿔 주세요.

좋은 후속 결과에는 ‘매출 20% 증가’와 ‘판촉이 원인’이 같은 등급으로 섞이지 않습니다. 실제 업무에서는 이 구분이 보고서의 신뢰도를 만듭니다. 숫자를 정확하게 계산했어도 원인을 만들어 내면 보고서 전체를 그대로 사용할 수 없습니다. 반대로 모른다고 말한 답변이 짧다는 이유로 낮게 평가하지 마세요.

정상 결과와 오류 해결

완료된 기록에는 서비스·환경·날짜, 화면상의 선택 항목, 동일한 질문 두 번의 결과, 직접 검산한 값, 근거 없는 주장 하나를 처리한 과정이 있어야 합니다. 두 답변의 문장이 달라도 이 기준을 만족하면 성공입니다. 관찰은 ‘A는 정확한 계산식을 제시했다’처럼 이번 결과에 한정해 적으세요.

로그인이 안 되면 공식 주소와 기존 로그인 방식을 먼저 확인합니다. 비밀번호나 인증 코드를 AI에 붙여 넣지 않습니다. 모델 선택 메뉴가 없으면 기본 설정으로 진행하고 상태를 기록하세요. 사용량 제한이 나오면 현재 결과를 저장하고 화면에 표시된 재개 조건을 따릅니다. 다른 계정을 만들어 제한을 우회하는 것은 실습 목표가 아닙니다. 계산이 틀리면 처음 제공한 수치를 다시 인용하며 분모와 단위를 구분해 달라고 요청합니다. 원인을 단정하면 그 문장을 삭제하고 확인 질문으로 바꾸세요.

한 서비스만 사용할 수 있을 때는 첫 채팅과 새 채팅의 차이를 관찰합니다. 결론은 ‘서비스 간 비교 미실시’로 적습니다. 진행하지 않은 비교를 진행한 것처럼 표에 채우지 않는 것도 중요한 검증 태도입니다. 기능이 없는 경우와 기능이 있지만 사용하지 않은 경우도 나누어 기록하세요.

복습 3문제와 정답

  1. ChatGPT와 GPT는 어떤 관계인가요? 정답: 앞은 사용자 서비스, 뒤는 모델 계열을 가리킵니다. 서비스에는 모델 외에도 설정과 도구 등 여러 요소가 포함됩니다.
  2. “9월 매출 20% 증가, 신학기 판촉 효과로 판단”에서 확인할 부분은 무엇인가요? 정답: 증가율은 제공 숫자로 검산할 수 있지만 판촉 효과는 별도 근거가 필요합니다. 상관관계만으로 원인을 확정하지 않습니다.
  3. 유료 계정에서 모델 선택 메뉴가 안 보이면 어떻게 하나요? 정답: 현재 환경과 계정 화면을 기록하고 공식 안내를 확인합니다. 특정 모델이나 무제한 이용을 추정하지 않고 기본 환경에서 가능한 실습을 진행합니다.

완료 체크

  • 서비스·모델·플랜을 서로 다른 항목으로 설명할 수 있습니다.
  • 같은 질문을 두 새 채팅에 입력하고 조건을 기록했습니다.
  • 200,000원과 20%를 계산기로 확인했습니다.
  • 원인·담당자를 만들어 낸 문장을 확인 질문으로 바꿨습니다.
  • 실제 회사 자료나 개인정보를 입력하지 않았습니다.
